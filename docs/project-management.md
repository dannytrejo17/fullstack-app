# Gestión del proyecto

## Tablero Kanban

El proyecto se organiza con un tablero Kanban en Trello con las siguientes columnas:

- Backlog: funcionalidades pendientes de planificar
- Todo: tareas listas para empezar
- In Progress: en desarrollo activo
- Review: terminadas, pendientes de revisión
- Done: completadas

## Funcionalidades y subtareas

### Backend Express
- Configurar proyecto Node.js con ES modules
- Crear estructura routes/controllers/services
- Implementar CRUD de productos
- Configurar CORS

### Frontend - Base
- Configurar Vite + React + TypeScript + Tailwind
- Instalar React Router
- Crear estructura de carpetas

### Frontend - Componentes
- Navbar con carrito
- ProductCard con Badge
- Spinner y ErrorMessage

### Frontend - Páginas
- Home con CTA
- Products con búsqueda
- ProductDetail con carrito
- CreateProduct con formulario validado
- Cart
- NotFound (404)

### Estado y lógica
- Custom hook useProducts
- CartContext con Provider

## Metodología aplicada

Se usa Kanban por ser un proyecto individual de tamaño pequeño-medio. No hay sprints fijos; las tareas se mueven según se van completando, lo que da flexibilidad para reordenar prioridades.
