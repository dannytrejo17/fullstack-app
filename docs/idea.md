# Idea del proyecto

## Descripción
La aplicación será un marketplace simple donde los usuarios pueden ver, crear y eliminar productos publicados.

## Problema que resuelve
Permite gestionar productos de forma sencilla sin usar plataformas complejas.

## Usuario objetivo
Personas que quieren publicar o consultar productos de segunda mano.

## Funcionalidades principales
- Ver lista de productos
- Crear un producto
- Eliminar un producto

## Funcionalidades opcionales
- Editar productos
- Filtros de búsqueda

## Posibles mejoras futuras
- Sistema de usuarios
- Chat entre compradores y vendedores
- Persistencia en base de datos real
